# llm-scratchpad

Experiments in applied LLM engineering — one self-contained project per directory.

| project | what it is |
|---|---|
| [geo-sft/](geo-sft/) | End-to-end supervised fine-tuning (QLoRA) lab for geoscience structured extraction, running entirely on Apple Silicon. Corpus acquisition → training-pair extraction → tokenizer work → training → monitoring → evaluation. |

Each project owns its own virtualenv, dependencies and README.
